## 🏎️ About The Project

Daytona USA 2: Power Edition brings Sega's classic Model 3 arcade racer to modern hardware, with enhanced resolutions, widescreen support, online multiplayer and modern steering-wheel compatibility.

Built from a full decompilation of the original arcade game, this native port preserves the original gameplay and arcade experience while introducing modern conveniences.

**The original arcade experience, brought to modern hardware.**

| `daytona2.zip` | 91,014,719 | `6d26677eb531870542347e7503762a27` | Optional |
| `scud.zip` | 63,208,291 | `d2d619b0ee5cbf74596431b28080c420` | Optional |

### Additional Tracks & Multiplayer Compatibility

While `dayto2pe.zip` is the only mandatory archive, both `daytona2.zip` and `scud.zip` add an additional track each.

**Installing all three archives is strongly recommended.** This ensures access to the complete track selection and helps maintain parity between players in multiplayer sessions.

ROM files are not included with this project.

## 🛠️ Installation

Choose your platform below and follow the relevant instructions.

### 🖥️ Windows PC

1. Extract Daytona USA 2 to your preferred directory.
2. Place `dayto2pe.zip` alongside `daytona2.exe`.
3. Place the optional `daytona2.zip` and `scud.zip` alongside `daytona2.exe`.
4. Power on your controllers, steering wheels and other peripherals **before launching the game**.
5. Run `daytona2.exe`.

**Example directory structure:**

```text
Daytona USA 2/
├── daytona2.exe
├── dayto2pe.zip
├── daytona2.zip       (Optional)
└── scud.zip           (Optional)
```

### 🎮 Xbox Series X

1. Extract the `Daytona2.appx` package.
2. Deploy the package to your Xbox Series X using the **Xbox Developer Portal**.
3. Place `dayto2pe.zip` in the root directory of your Xbox-formatted USB drive.
4. Place the optional `daytona2.zip` and `scud.zip` in the root directory of the same USB drive.
5. If no USB drive is available, transfer the ROM archives into the game's `LocalState` folder instead.
6. On the Xbox Developer Dashboard, highlight **Daytona USA 2** and press the **View button (Select)**.
7. Change the application type from **APP** to **GAME**.
8. Launch Daytona USA 2.

> **Important:** Ensure the application is configured as a **GAME**, not an APP, before launching.
